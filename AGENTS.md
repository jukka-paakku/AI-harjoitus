# AGENTS.md

## Projektin kuvaus
search picture files from specific folder and compare each other then mark and move 
similar pictures to another folder

## Tech Stack
- Framework: Python 3
- Kieli: python 
- Tietokanta: lite SQL
- Tyylitys: Tailwind CSS + shadcn/ui
- Tuetut kuvatiedostot : Jpeg + jpg
- Sama kuva voi olla useammin eri nimillä, siirrä  kaikki kopiot
